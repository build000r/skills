# Safe Continuation

For unavailable providers or harnesses, follow the shared
[Available Subagent Fallback](../../_shared/references/orchestration-contract.md#available-subagent-fallback).
Retain the actual agent identity, task ownership, and independent review.

For an existing failed worker, reconcile completed and uncertain effects and
fence the prior writer before transferring scope. The detailed NTM/account
recovery procedure belongs to `vibing-with-ntm`, in its
`references/safe-continuation.md`. Load it from the installed owning skill;
do not assume that private skill is a sibling of this public package.

A missing recovery harness blocks same-session restoration, not a fresh native
subagent dispatch from a verified checkpoint. Preserve the original evidence
and label the new dispatch honestly.
