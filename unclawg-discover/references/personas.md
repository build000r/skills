# Persona Framework (Generic)

Use this file when no project mode is available. Keep persona definitions concise,
actionable, and tied to observable search signals.

## Persona Set

| ID | Persona | Typical Goal | Priority |
|----|---------|--------------|----------|
| P1 | Active Buyer | Solve current pain quickly | Highest |
| P2 | Builder / Operator | Improve workflow reliability | High |
| P3 | Influencer / Amplifier | Share credible stories with reach | High |
| P4 | Incident Reporter | Surface failure stories with lessons | Medium |
| P5 | Enterprise Evaluator | Governance/compliance and process | Medium |

## Query Starter Packs

Replace placeholders for your domain.

### P1 - Active Buyer

- Reddit: `"{problem_keyword}" "need help"`
- Twitter/X: `"{problem_keyword}" "looking for"`
- LinkedIn: `"{problem_keyword}" "recommendation"`
- HN: `"{problem_keyword}" "Ask HN"`

### P2 - Builder / Operator

- Reddit: `"{workflow}" "production"`
- Twitter/X: `"{workflow}" "guardrails"`
- LinkedIn: `"{workflow}" "lessons learned"`
- HN: `"{workflow}" "architecture"`

### P3 - Influencer / Amplifier

- Twitter/X: `"{topic}" "thread"`
- LinkedIn: `"{topic}" "case study"`
- Reddit: `"{topic}" "my experience"`

### P4 - Incident Reporter

- Twitter/X: `"{tool_or_workflow}" "went wrong"`
- Reddit: `"{tool_or_workflow}" "broke"`
- HN: `"{tool_or_workflow}" "incident"`

### P5 - Enterprise Evaluator

- LinkedIn: `"{topic}" governance`
- HN: `"{topic}" compliance`
- Reddit: `"{topic}" audit trail`

## Selection Rules

1. Start with one primary persona + one secondary persona.
2. Require at least one high-intent query.
3. Add influencer/content queries only after buyer coverage is satisfied.
4. Do not exceed 12 paid queries per run unless explicitly approved.
