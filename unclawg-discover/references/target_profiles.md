# Target Profile Curation (Generic)

Use this when a mode file does not define account lists.

## Goal

Build a rotating list of accounts/communities where real users describe pains you can solve.

## Platform Defaults

### Reddit

- Prioritize niche subreddits where users share implementation detail.
- Keep a Tier 1 list (run every search) and Tier 2 list (weekly).

### Twitter/X

- Track builder/operator accounts that post original work.
- Track incident-reporting accounts that post concrete examples.

### LinkedIn

- Track decision-maker profiles with regular technical posting.
- Favor posts with meaningful comments over pure reaction count.

### Hacker News

- Use topic-driven queries; no fixed account list needed.

## Refresh Cadence

- Weekly: remove inactive/noise-heavy targets.
- Monthly: add new high-signal communities/accounts.

## Simple Scoring

Give each target 0-3 points per category:

- Relevance to current persona
- Signal density (real user stories)
- Engagement quality (comments with details)
- Freshness (active within 30 days)

Keep targets scoring >= 8/12.
